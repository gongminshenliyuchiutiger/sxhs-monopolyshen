# 漫遊雙溪步佈走讀神 🌿🎲

「漫遊雙溪步佈走讀神」是一款以新北市雙溪區在地特色、歷史文化與生態景點為主題的大富翁桌遊互動網頁。透過生動有趣的步道走讀闖關形式，讓玩家在擲骰漫遊中認識雙溪火車站、逐雨巷、打鐵舖、三忠廟、淡蘭古道與雙溪高中等在地地景與文化故事。

---

## 🎯 遊戲特色

- **在地走讀問答**：精選雙溪各大名勝古蹟與生態特色問答題目。
- **多人同樂**：支援 1 至 12 人遊玩，可自訂玩家名稱與代表色。
- **管理員題庫管理系統**：
  - 具備安全密碼驗證入口（不可逆 SHA-256 雜湊保護，安全不洩漏）。
  - 支援觀看全部景點的題目與選項。
  - 支援題目與選項編輯、正確答案重設、新增自訂題目與刪除題目。
  - 編輯後的題庫自動存入瀏覽器本地儲存（`localStorage`），亦可一鍵還原為系統預設題庫。
- **視聽互動**：
  - 背景音樂播放與音量自訂調節。
  - 深色／淺色主題模式切換。
  - 吉祥物互動點擊特效。
